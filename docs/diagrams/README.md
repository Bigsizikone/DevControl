# UML и Use Case Service Desk

Статус: целевая модель TO-BE. Дата: 10.09.2026.

Четыре схемы последовательности обмена и восемь листов Use Case, включая обзор и 60 подробных сценариев. Схемы отражают требования и целевые процессы, а не подтверждённое состояние реализации.

Основания: ЧТЗ, ПСИ и Целевое_описание_БП_Service_Desk.md в ../acceptance; модель прав src/domain/access.service.ts; функции ИБ и камер; четыре интеграционных сценария заказчика.

Повторные изображения актёра обозначают одну роль. Роли показаны по функциям, а не как подтверждённые коды доступа. Точные API 1С, привязка Telegram, правила согласования и выдачи прав уточняются при внедрении.
